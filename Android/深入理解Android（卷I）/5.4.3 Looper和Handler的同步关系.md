5.4.3Looper和Handler的同步关系Looper和Handler会有什么同步关系呢？它们之间确实有同步关系，而且如果不注意此关系，定会铸成大错！

同步关系肯定与多线程有关，我们来看下面的一个例子：

[--＞例子2]

```
        Handler thread2Handler = new Handler(looper) 不能替换成
        Handler thread2Handler = new Handler(Looper.myLooper())
```

上面这段代码的目的很简单：

线程1中创建线程2，并且线程2通过Looper处理消息。

线程1中得到线程2的Looper，并且根这是因为，myLooper返回的是调用线程的据这个Looper创建一个Handler，这样Looper，即Thread1的Looper，而不是我们发送给该Handler的消息将由线程2处想要的Thread2的Looper。

对这个问题，可以采用同步的方式进行处理。
