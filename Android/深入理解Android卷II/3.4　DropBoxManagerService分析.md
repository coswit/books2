# 3.4　DropBoxManagerService分析


DropBoxM anagerService(DBM S)用于生成和管理系统运行时的一些日志文件。这些日志文件大多记录的是系统或某个应用程序出错时的信息。

下面来分析这项服务。其中向System Server添加DBM S的代码如下：

```
ServiceManager.addService
(Context.DROPBOX_SERVICE,//服务名为
“dropbox”
new DropBoxManagerService(context,
new Fil e
("/data/system/dropbox")));
```
