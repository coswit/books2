# 7.1 概述


承接第6章介绍的WSC，本章将继续介绍Wi-Fi联盟推出的另外一项重要技术规范Wi-FiP2P。该规范的商品名为Wi-FiDirect，它支持多个Wi-Fi设备在没有AP的情况下相互连接。

在Android平台的Wi-Fi相关模块中，P2P的功能点主要集中在：

❑AndroidFramework中的WifiP2pService，其功能和WifiService类似，用于处理和P2P相关的工作。

❑wpa_supplicant中的P2P模块。

和WSC一样，本章的分析采用如下方法。

❑首先介绍P2P所涉及的基础知识。

❑然后分析和P2P相关的模块，包括Settings、WifiP2pService以及WPAS。
